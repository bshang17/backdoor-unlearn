# Logos

Pure-vector SVGs (no embedded bitmaps) with a tight `viewBox` and no
width/height, so CSS sizes them. Same files as `assets/logos/` in the
`optml-poster` skill.

| File | Mark | Provenance |
|---|---|---|
| `msu.svg` | Michigan State University, stacked lockup (Spartan helmet over wordmark), Spartan Green `#18453B` | potrace outline of the 5452 x 3716 px logo embedded in the group's DAT (UAI'22) poster |
| `optml.svg` | OPTML lab mark with "WE MAKE THE GLOBAL OPTIMAL" | potrace outline of the 8000 x 4000 px master on optml-group.github.io, set in near-black |
| `nus.svg` | National University of Singapore (shield + NUS wordmark) | SVG from the NUS article on English Wikipedia (`NationalUniversityofSingapore.svg`), viewBox tightened |
| `colm.svg` | COLM conference mark | colm.cc navbar SVG, recolored for a white background (white -> `#1b1f3b`, cyan -> `rgb(0,160,140)`), viewBox tightened |
